### Bug: Tray Blocked After Few Turns — FIXED

**Root Cause:** Circular dependency in gem shuffling when multiple colors exist. Complex logic tried to reorganize tray while adding incoming gems, creating deadlocks.

**Solution:** Simplified HandleTraySlotTapped:
1. When user taps tray gem, collect all gems of same color
2. Find empty board cells matching that color
3. Move gems to board in order (0,1,2,3...)
4. No tray reorganization, no shuffle logic
5. No circular dependencies
